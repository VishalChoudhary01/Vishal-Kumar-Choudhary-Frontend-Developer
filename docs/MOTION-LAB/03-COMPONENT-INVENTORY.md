# Motion Lab — Canonical Component Inventory

**Status: LOCKED INVENTORY**  
Each listed component has one individual specification file. Similar names with different interaction scopes remain separate; implementation logic should be shared only when behavior is genuinely identical.

## Milestones

**Milestone 1 — Core Motion:** Magnetic Button, Directional Hover Button, Ripple Button, 3D Tilt Card, Spotlight Card, Magnetic Card, Expandable Card, Line Mask Reveal, Character Reveal, Word Reveal, Scroll Reveal, Parallax Section, Animated Tabs, Accordion, Animated Toggle and Number Counter.

**Milestone 2 — Interface Interactions:** action variants, navigation, cards, forms, overlays, loading and progress.

**Milestone 3 — Scroll and Creative Motion:** pinned/linked scroll experiences, pointer systems, SVG and image effects, particles and galleries.

**Milestone 4 — Advanced and Data Motion:** creative effects and data visualization, with performance budgets and real data semantics.

## Naming and overlap decisions

- Magnetic Button moves the button within its bounded field. Cursor-Follow Button moves its label/indicator locally; it must not duplicate magnetic movement.
- Spotlight Card illuminates one card. Cursor Spotlight is a container/viewport layer for multiple surfaces.
- Card Stack is a static or user-controlled layered composition. Sticky Card Stack is scroll-bound and pinned.
- Number Counter is a count transition. Number Ticker is an odometer/rolling digit. Animated Number is formatted metric output with semantic context.
- Scroll Reveal is a general in-view entrance. Reveal Through Mask is scroll-linked clipping. Image Mask Transition is a state/slide transition.
- Custom Cursor replaces the visible pointer in an opted-in region. Cursor Follower draws a spring follower. Cursor Trail leaves fading history. Do not mount all three by default.
- Glow is local brand-tinted emission with a strict brightness limit. Spotlight is a restrained light overlay, not a new palette.

## Build rule

Each component is specified independently. Shared logic must be centralized when meaningful; do not create duplicate event systems, spring hooks, scroll observers or theme mappings.
