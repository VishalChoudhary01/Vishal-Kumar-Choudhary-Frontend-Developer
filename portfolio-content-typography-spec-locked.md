# Portfolio Content & Typography Specification

## Locked Font System

The portfolio uses **three locked font families**, plus a separate font for the visual logo.

| Role | Font Family | Weight | Purpose |
|---|---|---:|---|
| Display / Editorial | **Newsreader** | 400 | Hero title, section headings, major titles, large numbers |
| UI / Body | **Manrope** | 400–700 | Navigation, labels, body copy, descriptions, buttons, forms |
| System / Technical | **Azeret Mono** | 400–500 | Dates, counters, records, technical metadata |
| Logo | **Custom logo font** | 500–700 | `VKr.` only |

---

# Global Type Rules

## Newsreader — Display

- Weight: **400**
- Use for large editorial statements.
- Avoid artificially bolding it.
- Tight line-height: approximately `0.88–1`.
- It should provide the portfolio's visual personality.

## Manrope — UI / Body

- **400** — body and supporting copy
- **500** — secondary emphasis
- **600** — navigation, labels, tabs
- **700** — CTA / high-priority UI
- Normal body line-height: approximately `1.5–1.7`.

## Azeret Mono — System

- **400** — dates, metadata, counters
- **500** — important system information
- Uppercase where the content is a system label.
- Use sparingly so it feels like an engineering layer rather than a coding theme.
- Typical letter-spacing: `0.02–0.06em`.

## Logo

- Separate custom font.
- Do not use Newsreader, Manrope, or Azeret Mono for the final `VKr.` logo.
- The logo typeface should be selected specifically for recognizability and silhouette.

# 17. Design Principle

The portfolio's typography has four personalities:

**Newsreader = CRAFT**

**Manrope = CLARITY**

**Azeret Mono = ENGINEERING**

**Custom logo font = IDENTITY**

Keep the typography restrained. The portfolio's personality should come from the combination of **type + layout + motion + interaction**, not from constantly changing fonts or decorative effects.
