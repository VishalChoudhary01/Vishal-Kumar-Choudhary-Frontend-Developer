# Theme Toggle — Complete Working Implementation Notes

## Status

**LOCKED WORKING BASELINE**

This document is the implementation reference for the current theme-toggle system.

The implementation is designed for:

- Next.js App Router
- JavaScript / JSX
- Tailwind CSS v4
- `next-themes`
- `motion/react`
- `lucide-react`
- Native View Transition API

The primary requirement is a real page-wide cover/reveal transition, not a normal theme fade.

---

# 1. Required Visual Behavior

The default usage is:

```jsx
<ThemeToggle
    variant="rectangle"
    start="bottom-up"
/>
```

## Light → Dark

The **incoming dark snapshot** is the visible transition layer.

It starts from the configured origin and expands until the full page is dark.

For `bottom-up`:

```text
START

LIGHT
────────────────────────
────────────────────────
────────────────────────
────────────────────────
████████████████████████
████████████████████████
        DARK STARTS


MIDDLE

LIGHT
────────────────────────
────────────────────────
████████████████████████
████████████████████████
████████████████████████
        DARK


END

DARK
████████████████████████
████████████████████████
████████████████████████
████████████████████████
```

The dark layer must be visibly moving upward.

---

## Dark → Light

The **outgoing dark snapshot** is the visible transition layer.

It starts fully visible and retracts toward the same origin, exposing the light snapshot underneath.

```text
START

DARK
████████████████████████
████████████████████████
████████████████████████
████████████████████████


MIDDLE

DARK
████████████████████████
████████████████████████
------------------------


END

LIGHT
────────────────────────
────────────────────────
────────────────────────
────────────────────────
```

This must not become a sudden theme switch or a generic fade.

---

# 2. Final Architecture

The complete flow is:

```text
ThemeToggle
    ↓
useThemeToggle()
    ↓
next-themes
    ↓
document.startViewTransition()
    ↓
OLD + NEW snapshots
    ↓
direction-specific CSS
    ↓
<html class="light / dark">
    ↓
Tailwind dark:
```

Responsibilities:

```text
ThemeToggle
    = button + accessibility + icons

ActionSwapIcon
    = icon Motion animation

useThemeToggle
    = theme transition orchestration

next-themes
    = actual theme state + <html> class

View Transition API
    = page-wide visual transition

Tailwind
    = final light/dark styling
```

# 3. Theme State Ownership

Use `next-themes`:

```js
const {
    setTheme,
    resolvedTheme,
} = useTheme();
```

Current theme:

```js
const isDark =
    mounted &&
    resolvedTheme === "dark";
```

Target theme:

```js
const next =
    isDark
        ? "light"
        : "dark";
```

Direction:

```js
const goingToDark =
    next === "dark";
```

The actual theme change is:

```js
setTheme(next);
```

No second theme state mutation is needed.

# 4. `UIThemeProvider`

File:


Complete working implementation:

```jsx
"use client";

import { ThemeProvider } from "next-themes";

export function UIThemeProvider({
    children,
}) {
    return (
        <ThemeProvider
            attribute="class"
            defaultTheme="system"
            enableSystem
            disableTransitionOnChange={false}
        >
            {children}
        </ThemeProvider>
    );
}
```

## Why

`next-themes` needs to own the `<html>` theme class.

Expected states:

```html
<html class="light">
```

and:

```html
<html class="dark">
```

Keep:

```jsx
disableTransitionOnChange={false}
```

as part of this working baseline.

Do not add a second theme synchronization layer unless the transition architecture is intentionally being redesigned.

# 7. Complete `ActionSwapIcon`

File:

```text
src/app/components/motion/action-swap.jsx
```

```jsx
"use client";

import {
    AnimatePresence,
    motion,
} from "motion/react";

import { cn } from "@/app/lib/utils";

const variants = {
    blur: {
        initial: {
            opacity: 0,
            filter: "blur(8px)",
            scale: 0.8,
        },

        animate: {
            opacity: 1,
            filter: "blur(0px)",
            scale: 1,
        },

        exit: {
            opacity: 0,
            filter: "blur(8px)",
            scale: 0.8,
        },
    },
};

export function ActionSwapIcon({
    value,
    animation = "blur",
    className,
    children,
}) {
    const variant =
        variants[animation] ??
        variants.blur;

    return (
        <span
            className={cn(
                "relative inline-flex items-center justify-center",
                className,
            )}
        >
            <AnimatePresence
                mode="wait"
                initial={false}
            >
                <motion.span
                    key={value}
                    initial={
                        variant.initial
                    }
                    animate={
                        variant.animate
                    }
                    exit={
                        variant.exit
                    }
                    transition={{
                        duration: 0.22,
                        ease: [
                            0.4,
                            0,
                            0.2,
                            1,
                        ],
                    }}
                    className="inline-flex items-center justify-center"
                >
                    {children}
                </motion.span>
            </AnimatePresence>
        </span>
    );
}
```

## Why

The icon animation is intentionally separate from the page transition.

It handles:

```text
Moon ↔ Sun
```

It does not control the page theme.

# 8. Complete `ThemeToggle`

File:

```text
src/app/components/ui/ThemeToggle.jsx
```

```jsx
"use client";

import {
    Moon,
    Sun,
} from "lucide-react";

import {
    ActionSwapIcon,
} from "@/app/components/motion/action-swap";

import { cn } from "@/app/lib/utils";

import {
    useThemeToggle,
} from "@/app/hooks/useThemeToggle";

export function ThemeToggle({
    variant = "rectangle",
    start = "bottom-up",
    className,
    iconClassName,
    ...rest
}) {
    const {
        isDark,
        mounted,
        toggle,
    } = useThemeToggle({
        variant,
        start,
    });

    return (
        <button
            type="button"
            aria-label={
                mounted && isDark
                    ? "Switch to light mode"
                    : "Switch to dark mode"
            }
            onClick={toggle}
            className={cn(
                "flex items-center justify-center",
                className,
            )}
            {...rest}
        >
            {mounted ? (
                <ActionSwapIcon
                    value={
                        isDark
                            ? "dark"
                            : "light"
                    }
                    animation="blur"
                    className={
                        iconClassName
                    }
                >
                    {isDark ? (
                        <Sun
                            className={
                                iconClassName
                            }
                        />
                    ) : (
                        <Moon
                            className={
                                iconClassName
                            }
                        />
                    )}
                </ActionSwapIcon>
            ) : (
                <span
                    className={
                        iconClassName
                    }
                    aria-hidden="true"
                />
            )}
        </button>
    );
}
```

```jsx
/* =========================================================
   RECTANGLE ORIGINS
   ========================================================= */

const RECT_FROM = {
    "top-left":
        "inset(0 100% 100% 0)",

    "top-right":
        "inset(0 0 100% 100%)",

    "bottom-left":
        "inset(100% 100% 0 0)",

    "bottom-right":
        "inset(100% 0 0 100%)",

    center:
        "inset(50% 50% 50% 50%)",

    "bottom-up":
        "inset(100% 0 0 0)",
};


/* =========================================================
   CIRCLE ORIGINS
   ========================================================= */

const CIRCLE_ORIGIN = {
    "top-left":
        "0% 0%",

    "top-right":
        "100% 0%",

    "bottom-left":
        "0% 100%",

    "bottom-right":
        "100% 100%",

    center:
        "50% 50%",

    "bottom-up":
        "50% 100%",
};


/* =========================================================
   CLEANUP
   ========================================================= */

function cleanupTransitionState(root) {
    delete root.dataset.themeTransition;
    delete root.dataset.themeTransitionDirection;

    root.style.removeProperty(
        "--theme-transition-from",
    );

    root.style.removeProperty(
        "--theme-transition-origin",
    );

    root.style.removeProperty(
        "--theme-transition-slat",
    );
}


/* =========================================================
   HOOK
   ========================================================= */

export function useThemeToggle({
    variant = "rectangle",
    start = "bottom-up",
} = {}) {
    const {
        setTheme,
        resolvedTheme,
    } = useTheme();

    const reduce =
        useReducedMotion() ?? false;

    const [
        mounted,
        setMounted,
    ] = useState(false);


    /* -----------------------------------------------------
       Hydration-safe mount state
       ----------------------------------------------------- */

    useEffect(() => {
        setMounted(true);
    }, []);


    /* -----------------------------------------------------
       Inject transition stylesheet once
       ----------------------------------------------------- */

    useEffect(() => {
        if (
            document.getElementById(
                VT_STYLE_ID,
            )
        ) {
            return;
        }

        const style =
            document.createElement(
                "style",
            );

        style.id =
            VT_STYLE_ID;

        style.textContent =
            VT_CSS;

        document.head.appendChild(
            style,
        );
    }, []);


    /* -----------------------------------------------------
       Current theme
       ----------------------------------------------------- */

    const isDark =
        mounted &&
        resolvedTheme === "dark";


    /* -----------------------------------------------------
       Toggle
       ----------------------------------------------------- */

    const toggle = () => {
        /*
         * Determine target theme.
         */
        const next =
            isDark
                ? "light"
                : "dark";


        /*
         * Determine direction.
         */
        const goingToDark =
            next === "dark";


        /* -------------------------------------------------
           Fallback
           ------------------------------------------------- */

        if (
            reduce ||
            !(
                "startViewTransition" in
                document
            )
        ) {
            setTheme(next);
            return;
        }


        const root =
            document.documentElement;


        /* -------------------------------------------------
           Expose direction to CSS
           ------------------------------------------------- */

        root.dataset.themeTransitionDirection =
            goingToDark
                ? "to-dark"
                : "to-light";


        /* -------------------------------------------------
           Configure transition variant
           ------------------------------------------------- */

        if (
            variant ===
            "rectangle"
        ) {
            root.style.setProperty(
                "--theme-transition-from",
                RECT_FROM[start],
            );

            root.dataset.themeTransition =
                "rect";
        }

        else if (
            variant ===
            "blinds"
        ) {
            root.dataset.themeTransition =
                "blinds";
        }

        else {
            root.style.setProperty(
                "--theme-transition-origin",
                CIRCLE_ORIGIN[start],
            );

            root.dataset.themeTransition =
                variant;
        }


        /* -------------------------------------------------
           Native View Transition
           ------------------------------------------------- */

        let transition;

        try {
            transition =
                document.startViewTransition(
                    () => {
                        /*
                         * IMPORTANT:
                         *
                         * Keep the theme mutation here.
                         *
                         * Do not replace this with a
                         * separate DOM class mutation.
                         */
                        setTheme(next);
                    },
                );
        } catch {
            setTheme(next);

            cleanupTransitionState(
                root,
            );

            return;
        }


        /* -------------------------------------------------
           Cleanup
           ------------------------------------------------- */

        transition.finished
            .catch(() => {})
            .finally(() => {
                cleanupTransitionState(
                    root,
                );
            });
    };


    return {
        isDark,
        mounted,
        toggle,
    };
}
```

# 10. Why the `data-theme-transition` State Exists

The transition needs to communicate temporary state from JavaScript to CSS.

For example:

```html
<html
    data-theme-transition="rect"
    data-theme-transition-direction="to-dark"
>
```

This tells CSS:

```text
variant = rectangle
direction = entering dark
```

For reverse:

```html
<html
    data-theme-transition="rect"
    data-theme-transition-direction="to-light"
>
```

This tells CSS:

```text
variant = rectangle
direction = entering light
```

The attributes exist only while the View Transition is active and are removed afterward.

---

# 11. Why Direction Uses Different Snapshots

The browser creates:

```text
OLD
NEW
```

snapshots.

For:

```text
Light → Dark
```

the incoming dark snapshot is:

```text
NEW
```

Therefore:

```css
::view-transition-new(root)
```

is animated.

For:

```text
Dark → Light
```

the existing dark snapshot is:

```text
OLD
```

Therefore:

```css
::view-transition-old(root)
```

is animated.

This is the core of the opposite physical motion.

```jsx
text-zinc-950 dark:text-white
```

Do not manually inspect theme state just to choose static Tailwind colors.

`next-themes` changes the HTML class and Tailwind reacts to it.

---

# 18. Hero Rule

The Hero should not have a theme color transition.

Correct:

```jsx
<section
    className={cn(
        "relative flex min-h-screen items-center overflow-hidden",
        "bg-white text-zinc-950",
        "dark:bg-zinc-950 dark:text-white",
    )}
>
```

Avoid:

```text
transition-colors duration-500
```

on the theme background/text.

## Why

That would create a second theme animation in addition to the View Transition.

Normal hover transitions are still allowed.

```text
dark:text-zinc-400

dark:hover:bg-white/10
```

Its visual theme should come from Tailwind.

No manual JavaScript theme switching is needed inside the Navbar.

# 25. Cleanup Rules

The following temporary state must always be removed after the transition:

```text
data-theme-transition
data-theme-transition-direction
--theme-transition-from
--theme-transition-origin
--theme-transition-slat
```

The cleanup function:

```js
function cleanupTransitionState(root) {
    delete root.dataset.themeTransition;
    delete root.dataset.themeTransitionDirection;

    root.style.removeProperty(
        "--theme-transition-from",
    );

    root.style.removeProperty(
        "--theme-transition-origin",
    );

    root.style.removeProperty(
        "--theme-transition-slat",
    );
}
```

Cleanup occurs after:

```js
transition.finished
```

# 27. Debugging Sequence

If the animation disappears, inspect the problem in this order:

```text
1. Is next-themes changing the theme?
        ↓
2. Does <html> change class?
        ↓
3. Does document.startViewTransition exist?
        ↓
4. Does <html> temporarily receive
   data-theme-transition?
        ↓
5. Is direction:
   to-dark or to-light?
        ↓
6. Is the correct snapshot selected?
        ↓
7. Is clip-path changing?
        ↓
8. Does the final theme remain correct?
```

For dark entry:

```text
data-theme-transition-direction="to-dark"
```

and:

```text
::view-transition-new(root)
```

must be animated.

For light return:

```text
data-theme-transition-direction="to-light"
```

and:

```text
::view-transition-old(root)
```

must be animated.

# 31. Final Implementation Principles

### Principle 1

`next-themes` owns the theme.

### Principle 2

View Transition API owns the page-wide visual transition.

### Principle 3

Motion owns icon animation.

### Principle 4

Tailwind owns component light/dark styling.

### Principle 5

Entering dark animates the `NEW` snapshot.

### Principle 6

Leaving dark animates the `OLD` snapshot.

### Principle 7

Never replace the cover/reveal with a generic fade.

### Principle 8

Never add a second theme animation to the page elements.

### Principle 9

Always clean temporary transition state.

### Principle 10

Test both directions after every transition change.
